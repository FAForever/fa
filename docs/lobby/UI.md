# UI element priorities

Based on the lobby features, this document collects the information requirements that need to be displayed in the UI.
As we can't display everything at once, we will have to make use of additional dialog windows. To understand what needs to be immediately present and what can be tucked away behind additional clicks, we give a priority score.

- **1** must be immediately visible
- **2** can require a click or hovering to show, but would be nice to have immediately visible if we can afford the space
- **3** can and probably should require a click to show to not clutter the main ui
- **4** even lower priority
- **0** we shouldn't / don't need to display this at all
