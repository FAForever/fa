- (#6962) This PR reverts the nerfs to the Exodus' `TurretYawRange` and `TurretYawSpeed` introduced in [commit 3177522](https://github.com/FAForever/fa/commit/3177522abd84fede5bb841885d35b1ffd1c8c63a#diff-0c06583a0f25a70aeb6f740ffe7c8689f3e775164f98c38704969aa9b7aadd96L305-R306). These changes were a significant nerf to the unit's microability, giving it almost the same `TurretYawSpeed` as the Salem, and nearly the same `TurretYawRange`. Since the Exodus is no longer considered overpowered, these changes make microing it more rewarding again and help differentiate it further from the Salem.

  **Exodus Class: T2 Destroyer (UAS0201):**
  - Oblivion Cannon
    - TurretYawRange: 150 --> 160
    - TurretYawSpeed: 90 --> 100
